PROJECT DETAILS

Title: MERCER VALE — Fashion Website & Motion
Categories: Web Design, UI/UX, Art Direction
Tags: fashion, editorial, web design, typography, motion design, responsive

DESCRIPTION

MERCER VALE is a concept website for an independent clothing house. The project brings together fashion-retail research, art direction, information architecture, English editorial copy and a working responsive interface.

Large-scale photography establishes the atmosphere of a campaign. Categories, search and a full-screen lookbook give visitors a clear route into the clothing references. Motion connects the page through line reveals, expanding photographic frames and a centred loading wordmark with a thin progress bar and a soft fade into the campaign.

The case study documents the research, page structure, colour system, typography, desktop and mobile compositions, interface details and copy development. The collection remains in development; the project makes no claims about measured sales impact.
